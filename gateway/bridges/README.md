# 外部命令桥接

网关本身不含业务逻辑。需要做「非 HTTP 转发」的事（比如往内部系统写数据）时，
在这里放一个独立可执行文件，网关只负责把处理好的文本交给它。

## 约定

- 网关通过环境变量 `BRIDGE_CMD` 指定的命令调用
- 输入：待处理的文本，从 **stdin** 传入（UTF-8）
- 输出：单行 JSON 到 **stdout**，形如 `{"ok": true, "detail": "..."}` 或 `{"ok": false, "error": "..."}`
- 退出码：0 成功，非 0 失败
- 超时：由网关的 `BRIDGE_TIMEOUT` 控制，超时即中止
- 脚本自己负责鉴权、会话、重试等一切细节；网关不管

这样换后端只改 `BRIDGE_CMD`，网关代码不动。
